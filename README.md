# Porto Jenal — Junior Graphic Designer

Website portofolio berbasis Next.js (App Router) untuk Jaenal Arifin.

## Menjalankan di komputer

1. Install Node.js versi LTS.
2. Ekstrak folder `porto-jenal`.
3. Buka terminal pada folder project.
4. Jalankan:

```bash
npm install
npm run dev
```

5. Buka http://localhost:3000

Untuk build production:

```bash
npm run build
npm start
```
